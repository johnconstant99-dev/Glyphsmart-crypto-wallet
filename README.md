# Glyph - Smart Crypto Wallet Landing Page Zero Dependencies

A Pen created on CodePen.

Original URL: [https://codepen.io/Kasey-Kierra/pen/raWNXwz](https://codepen.io/Kasey-Kierra/pen/raWNXwz).

🔐 A modern, fully-responsive crypto wallet landing page built with cutting-edge Web3 aesthetics.

This design pushes the boundaries of fintech UI with:

— Orbitron (display) × Exo 2 (body) - a typography match
— Animated phone mockups showcasing wallet flows
— Glowing orb effects and gradient overlays for that premium feel

⚡ Interactive Features
— Live ticker with seamless marquee animation
— Scrollable token cards with sparkline charts
— Smooth scroll navigation w/ IntersectionObserver
— Mobile menu with keyboard support (Escape to close)
— Scroll-to-top button + toast notifications

♿ Built Right
— Full accessibility: ARIA labels, semantic HTML, focus states
— Mobile-first responsive design (600px → 900px → 1100px breakpoints)
— Comprehensive CSS design system (100+ custom properties)
— Zero JavaScript frameworks — just vanilla magic

Perfect for anyone exploring modern crypto UI, design systems, or just admiring clean interactive design. Great reference for your next fintech project! 🚀
